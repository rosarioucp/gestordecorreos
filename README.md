# Gestor de Correos
Sistema de gestión de correos electrónicos desarrollado en TypeScript. Permite manejar contactos, enviar y recibir correos, organizarlos en bandejas, buscarlos y filtrarlos. Combina programación orientada a objetos y programación funcional, y fue desarrollado con TDD.

## Requisitos
Tener instalado Node.js versión 20 o superior y Git.
## Instalación
Clonar el repositorio:
git clone https://github.com/rosarioucp/gestordecorreos.git
Entrar a la carpeta del proyecto:

## Instalar las dependencias:
npm install
## Ejecutar los tests
npm test
## Ver la cobertura
npm run coverage
